# Contributing

Contributions to this repository (pull requests, patches and code attached to
issues) are accepted only under Section 5 (Contributions) of the PhysiCar
Community License 1.0 (see LICENSE). By submitting a contribution you confirm
that you have the right to submit it and that it is provided under those terms.

Before opening a pull request:

- Write code and comments in English.
- Do not add third-party code or assets without recording their origin and
  license in NOTICE (and THIRD_PARTY_LICENSES where that file exists).
- Describe how you tested the change, on a PhysiCar robot or in the simulator.
- Do not change VERSION; releases are tagged by the maintainers.
